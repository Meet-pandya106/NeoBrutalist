# NeoBrutalist — Website Template

A bold, editorial, neo-brutalist website template package engineered for rapid hackathon deployment. Built with Next.js 16 (App Router), TypeScript, Tailwind CSS, Zustand, and anime.js v4.

---

## 📁 Repository Structure

- **[`/flex`](./flex)**: The complete Next.js 16 neo-brutalist web application.
  - 5 full presets: Agency, Tool/Calculator, Dashboard/Analytics, SaaS, Event
  - Style modes: `brutal`, `clean`, `soft`
  - Floating Dev Panel (toggle with backtick key `` ` ``)
  - Full component library and interactive styleguide (`/styleguide`)
- **[`/asset`](./asset)**: High-resolution visual assets and graphics used across the templates.

---

## ⚡ Quick Start

```bash
# 1. Navigate to the template project
cd flex

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Production build
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the application.  
Open [http://localhost:3000/styleguide](http://localhost:3000/styleguide) to explore components and design tokens.

For more details, see the documentation in [**flex/README.md**](./flex/README.md).
